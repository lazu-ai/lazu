# I18n Glossary

Keep this file small. It is only for terms that repeatedly appear in the product UI or operator docs.

| 中文 | English | Notes |
| --- | --- | --- |
| 倍率 | Ratio | Pricing multiplier. Prefer `ratio` in code/config. |
| 令牌 | Token | Can mean API key, access token, or model token. Clarify by context. |
| 渠道 | Channel | Provider/channel route used by the gateway. |
| 分组 | Group | User/token grouping that affects access or pricing. |
| 额度 | Quota | Available account usage balance. |
| 提示 | Prompt | Model input instruction. |
| 补全 | Completion | Model output in OpenAI-compatible wording. |
| 模型倍率 | Model Ratio | Input-side model billing ratio. |
| 补全倍率 | Completion Ratio | Output-side billing ratio. |
| 固定价格 | Price per call | Per-call pricing mode. |
| 按量计费 | Pay-as-you-go | Usage-based billing. |
| 超级管理员 | Root User | Highest-privilege admin. |
| 管理员 | Admin User | Admin user. |
| 普通用户 | Normal User | Regular user. |
| 充值 | Top Up | Add quota/credit. |
| 密钥 | Key | API/provider secret. |
| 优先级 | Priority | Channel selection priority. |
| 权重 | Weight | Load balancing weight. |
| 代理 | Proxy | Proxy server setting. |
| 模型重定向 | Model Mapping | Request model-name rewrite. |
| 两步验证 | Two-Factor Authentication | 2FA. |

## Rules

- Keep product-facing terms consistent with the Chinese source keys in `apps/web/src/i18n/locales/zh.json`.
- Technical acronyms such as API, JSON, SDK, and 2FA can stay in English.
- Do not add one-off strings here; add only terms that prevent recurring translation drift.
