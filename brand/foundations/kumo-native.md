# Kumo Native — retained baseline and history

**Status: PARTIALLY SUPERSEDED**

The July 11, 2026 direction established semantic surfaces, task-oriented page
structure and restrained interaction. [Yunmu](yunmu-console.md) superseded its
palette and surface treatment on August 20. Warm-orange actions and primary
chart series are retired. This page is retained for existing references, not
as a competing visual specification.

## Retained principles

- Geist for Latin and numbers, system CJK, IBM Plex Mono for code and IDs.
- Readable page hierarchy, task headers and efficient resource lists.
- Semantic surfaces and hairlines; shadows for real elevation.
- Approximately 1.5px icons readable at 16px.
- Direct 120–180ms motion without bounce, respecting reduced motion.
- State communicated through text and shape as well as color.
- Copy that states the fact, impact and one action.

For implementation read [BRAND.md](../BRAND.md), [Yunmu](yunmu-console.md),
[current colors](color-system.md), [UI](ui-system.md),
[component contracts](component-contracts.md) and the relevant page foundation.
Historical orange color tables and superseded recipes remain in Git history.
