Read the README.md file within this skill, then read BRAND.md and the files it marks as LOCKED.

Only locked decisions may be treated as production constraints. Design explorations (kept in the private ops repository as `lazu-ops:brand/explorations/`) are review artifacts, not approved rules. If creating visual artifacts, reuse the locked tokens and current assets while clearly labeling any unresolved choices. If working on production code, copy approved assets and follow the locked rules exactly.

If invoked without further guidance, ask what the user wants to build and whether pending decisions should remain neutral or be explored as alternatives.
