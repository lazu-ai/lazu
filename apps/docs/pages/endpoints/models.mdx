## Which model endpoint should I use?

<EndpointGrid>
  <EndpointTile title="/v1/models">
    OpenAI-compatible model list for existing SDKs and tools.
  </EndpointTile>
  <EndpointTile title="/api/models/catalog">
    Rich token-scoped catalog for agents, routing, pricing, modalities, endpoint
    support, parameters and usage/cache metadata.
  </EndpointTile>
</EndpointGrid>

## Response fields

<FieldList>
  <Field name="object" type="string">
    Always <code>list</code>.
  </Field>
  <Field name="data" type="object[]">
    Accessible model records for the current API key.
  </Field>
  <Field name="data[].id" type="string">
    Model ID.
  </Field>
  <Field name="data[].object" type="string">
    Usually <code>model</code>.
  </Field>
  <Field name="data[].owned_by" type="string">
    Provider or owner label.
  </Field>
</FieldList>

## Filtering behavior

A model appears here only when:

1. It is enabled on at least one usable Lazu channel.
2. The current API key is allowed to access it.
3. The token's model restrictions do not exclude it.

If an agent needs to choose well, read [Model catalog](/models/catalog) first.
