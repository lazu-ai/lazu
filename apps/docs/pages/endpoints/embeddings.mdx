## Example: semantic search

Embed the documents once, embed each query, and rank by cosine similarity.
`BAAI/bge-m3` maps more than 100 languages into one space, so an English query
finds Chinese or Japanese documents without translation.

```python
import numpy as np
from openai import OpenAI

client = OpenAI(base_url="https://api.lazu.ai/v1", api_key="YOUR_LAZU_KEY")

docs = [
    "Reset your password from Settings → Security.",
    "账单每月 1 日生成，可在控制台下载发票。",
    "API キーはプロジェクトごとに発行できます。",
]

def embed(texts):
    resp = client.embeddings.create(model="BAAI/bge-m3", input=texts)
    vectors = np.array([item.embedding for item in resp.data])
    return vectors / np.linalg.norm(vectors, axis=1, keepdims=True)

doc_vectors = embed(docs)
query_vector = embed(["Where can I download my invoice?"])[0]

scores = doc_vectors @ query_vector
for index in scores.argsort()[::-1]:
    print(f"{scores[index]:.3f}  {docs[index]}")
```

## Limits

- **Per-input token limit.** The catalog's `input_limit` is the most tokens one
  input may hold (8192 for `BAAI/bge-m3`). A longer input is refused with
  `400 context_length_exceeded` (LZ-1005) and costs nothing. Split long
  documents into chunks below the limit; a few hundred to a thousand tokens per
  chunk usually retrieves better anyway.
- **Batches.** Send an array to embed several texts in one request. For large
  jobs, send batches of tens to a few hundred inputs and retry a failed batch
  rather than one huge request.
- **Empty input.** An empty string is refused by most models; drop empty chunks
  before sending.

## Billing

Embeddings bill input tokens only, at the model's input price on
[Pricing & lanes](/models/pricing). When the provider reports how many tokens
it read, that count is billed. When it does not, Lazu counts the input with a
standard tokenizer; that count can differ by a few percent from the model's own
tokenizer, in either direction depending on the language. Failed requests are
not charged. Each request's billed tokens and amount are in `usage` and in the
request detail.

## Common models

| Model                    | Dimensions | Max input tokens | Custom `dimensions` | Notes                           |
| ------------------------ | ---------- | ---------------- | ------------------- | ------------------------------- |
| `BAAI/bge-m3`            | 1024       | 8192             | No                  | Open weights, 100+ languages    |
| `text-embedding-3-small` | 1536       | 8191             | Yes                 | OpenAI, low cost                |
| `text-embedding-3-large` | 3072       | 8191             | Yes                 | OpenAI, highest quality         |
| `gemini-embedding-001`   | 3072       | 2048             | Yes (768, 1536)     | Google                          |

Which of these your key can call depends on the deployment; the catalog is the
source of truth.
