## Request body

<FieldList>
  <Field name="model" type="string" required>
    Embedding model ID from <code>/api/models/catalog</code>.
  </Field>
  <Field name="input" type="string | string[]" required>
    Text input or ordered batch of text inputs. The response preserves order.
  </Field>
  <Field name="dimensions" type="integer" nullable>
    Optional vector dimension for models that support truncation.
  </Field>
  <Field
    name="encoding_format"
    type="string"
    nullable
    values={["float", "base64"]}
  >
    Output encoding format when supported by the upstream provider.
  </Field>
</FieldList>

## Response

<FieldList>
  <Field name="object" type="string">
    Usually <code>list</code>.
  </Field>
  <Field name="data" type="object[]">
    One embedding item per input.
  </Field>
  <Field name="data[].embedding" type="number[] | string">
    Vector values or base64-encoded vector depending on
    <code>encoding_format</code>.
  </Field>
  <Field name="usage.prompt_tokens" type="integer">
    Input tokens used for embedding.
  </Field>
</FieldList>

## Batch guidance

Pass an array for small batches. For large data jobs, chunk client-side so each
request stays within provider body-size and token limits.
