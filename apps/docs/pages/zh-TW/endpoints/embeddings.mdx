## 範例：語意檢索

文件先向量化一次，每個查詢再向量化，依餘弦相似度排序。`BAAI/bge-m3` 把 100 多種語言映射到同一個向量空間，英文查詢不必翻譯就能找到中文或日文文件。

```python
import numpy as np
from openai import OpenAI

client = OpenAI(base_url="https://api.lazu.ai/v1", api_key="YOUR_LAZU_KEY")

docs = [
    "Reset your password from Settings → Security.",
    "账单每月 1 日生成，可在控制台下载发票。",
    "API キーはプロジェクトごとに発行できます。",
]

def embed(texts):
    resp = client.embeddings.create(model="BAAI/bge-m3", input=texts)
    vectors = np.array([item.embedding for item in resp.data])
    return vectors / np.linalg.norm(vectors, axis=1, keepdims=True)

doc_vectors = embed(docs)
query_vector = embed(["Where can I download my invoice?"])[0]

scores = doc_vectors @ query_vector
for index in scores.argsort()[::-1]:
    print(f"{scores[index]:.3f}  {docs[index]}")
```

## 限制

- **單筆輸入 token 上限。** 目錄中的 `input_limit` 是一筆輸入最多能有多少 token（`BAAI/bge-m3` 為 8192）。超長輸入會被拒絕，回傳 `400 context_length_exceeded`（LZ-1005），不扣費。長文件請先切塊到上限以下；每塊幾百到一千 token 通常檢索效果也更好。
- **批次。** 傳陣列即可一次向量化多筆文字。大型任務建議每批幾十到幾百筆，失敗時重試那一批，而不是送出一個超大請求。
- **空輸入。** 多數模型會拒絕空字串，送出前請移除空塊。

## 計費

Embeddings 只依輸入 token 計費，單價見[定價與通道](/zh-TW/models/pricing)中該模型的輸入價。服務商回傳了讀取的 token 數時依它計費；沒有回傳時，Lazu 以通用分詞器在本地計數，與模型自帶分詞器相比可能相差幾個百分點，偏多或偏少取決於語言。失敗的請求不扣費。每次請求的計費 token 與金額都在 `usage` 和請求詳情中。

## 常見模型

| 模型                     | 維度 | 單筆最大輸入 token | 自訂 `dimensions`   | 說明                     |
| ------------------------ | ---- | ------------------ | ------------------- | ------------------------ |
| `BAAI/bge-m3`            | 1024 | 8192               | 不支援              | 開放權重，100+ 種語言    |
| `text-embedding-3-small` | 1536 | 8191               | 支援                | OpenAI，低成本           |
| `text-embedding-3-large` | 3072 | 8191               | 支援                | OpenAI，效果最好         |
| `gemini-embedding-001`   | 3072 | 2048               | 支援（768、1536）   | Google                   |

你的 Key 能呼叫哪些模型取決於部署，以模型目錄為準。
