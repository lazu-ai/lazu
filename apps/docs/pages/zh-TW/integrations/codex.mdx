# Codex CLI

在 `~/.codex/config.toml` 設定 Lazu 原生 Responses 端點並匯出 `LAZU_API_KEY`：

```toml
model_provider = "lazu"
model = "gpt-6.2-astra"

[model_providers.lazu]
name = "Lazu"
base_url = "https://api.lazu.ai/v1"
env_key = "LAZU_API_KEY"
wire_api = "responses"
```
