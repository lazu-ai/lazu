# 更新日誌

## 2026-10-29 — 移除搜尋介面

- `POST /v1/search` 與 `/api/search/backends*` 已提前於原定的 2026-11-01 移除，下列控制台頁面、狀態頁搜尋列與 API 金鑰搜尋欄位也一併移除。這兩個介面現在回傳 404 `endpoint_not_supported`（LZ-1010）。
- 錯誤碼 LZ-7302、LZ-7861、LZ-7862 停用。原本的搜尋文件頁會轉址到本更新日誌。

## 2026-10-29 — 棄用搜尋介面

- `POST /v1/search` 及檢索後端管理介面（`/api/search/backends*`）已棄用，2026-11-01 之後的第一個版本將移除。這些介面的回應現在帶有 `Deprecation`、`Sunset` 標頭。api.lazu.ai 上沒有客戶呼叫過該介面，所以窗口比一般的 90 天短。
- 一併移除：控制台的「檢索後端」頁、狀態頁中的搜尋列，以及 API 金鑰的 `search_limits_enabled`、`search_providers`、`search_domain_allowlist` 欄位。
- 不受影響：模型內建的聯網搜尋工具（`/v1/responses` 與 Chat 上的 `web_search`、`/v1/messages` 上的 Claude 聯網搜尋）照常可用，計費不變。依賴 `/v1/search` 的自部署使用者可以直接呼叫搜尋服務商。

## 2026-10-26 — 棄用五項自部署設定

- `LogConsumeEnabled=false` 已棄用。2027-01-24 之後消費日誌將一律寫入；如需控制儲存空間，請改用 `LOG_RETENTION_DAYS`。
- Worker 下載代理（`WorkerUrl`、`WorkerValidKey`、`WorkerAllowHttpImageRequestEnabled`）已棄用。2027-01-24 之後媒體下載與 webhook 將直接連線，並依媒體抓取政策檢查位址。
- `general_setting.quota_display_type=TOKENS` 已棄用。2027-01-24 之後日誌文字中的金額一律以美元顯示，與控制台一致。
- `SETTLEMENT_OUTBOX_ENABLED=true` 已棄用。2027-01-24 之後結算 outbox 及其對帳任務將移除；結算失敗仍由失敗對帳任務復原。
- `DataExportEnabled`（連同 `DataExportInterval`）已棄用。2027-02-01 之後按小時彙總的 `usage_data` 表與 `GET /api/data/` 將移除；儀表板與用量頁不讀取它們。如需保留，請先匯出這張表。
- 設定了其中任一項的部署，啟動時會輸出一行 `deprecated setting:` 提示。詳見部署指南的「Deprecated settings」一節。
## 2026-10-26 — 一批 API 路由計畫下線

下列路由現在會回傳 `Deprecation`、`Sunset` 回應標頭；有替代介面的，還會回傳 `Link: <…>; rel="successor-version"`。管理介面在 2026-12-01 之後刪除，使用者介面和公開 API 在 2027-02-01 之後刪除。每次刪除前都會核對正式環境的存取紀錄。

- `POST /api/user/self/stripe/pay`：改用 `POST /api/user/stripe/pay`。`POST /api/user/stripe/amount`：金額由控制台計算。
- `/api/user/used-models`、`/api/user/models/classified`（改用 `/api/user/models/catalog`）、`PUT /api/user/:id/has_topped_up`、`/api/data/self`（改用 `/api/data/dashboard/self`）、`/api/log/token`（改用 `/api/log/self`）、`/api/usage/token`（改用 `/api/usage/summary`）、`/api/log/self/in_flight`（改用 `/api/log/self/tasks`）、`/api/log/self/tasks/:id`。
- Playground 路由 `/pg/chat/completions`；控制台已沒有 Playground。
- 回傳 501 的 `/v1/fine-tunes*`、`/v1/images/variations`、`DELETE /v1/models/:model`，以及餘額介面 `/v1/dashboard/billing/*`、`/dashboard/billing/*`，由控制台錢包取代。
- `/api/community/*` 和 `/api/models/rankings`。
- 管理介面（2026-12-01 之後刪除）：`/api/channel/tag/*`、`/api/channel/batch*`（改用逐一渠道操作），`POST /api/notification/email/{send,announcement}`（改用公告），`/api/upload/*`（改用 `config.yaml` 裡的排程上傳），`/api/workers/*`，`GET /api/data/`（它讀取的 `usage_data` 表也已棄用）。

## 2026-09-30 — Agent 工作階段、請求明細與長上下文价格

- 以任務、模型及逐請求明細重做 Agent 工作階段。
- 新增工作階段活動視圖與子代理路線，觀測範圍為網關活動，不含本機工具。
- 長上下文價格接入成本計算、請求明細與公開模型頁；實際階梯依模型與路線設定。
- sitemap 修改日期採用真實內容變更時間。

日期為原始碼合併時間，自部署實例以部署版本為準。另見[工作階段費用核對指南](/zh-TW/agent-session-costs)。

## 2026-05-28 — Usage 中繼資料與快取欄位

- OpenAI-compatible 回應新增標準化快取欄位：`cached_tokens`、
  `cache_write_tokens`、`cache_write_5m_tokens`、`cache_write_1h_tokens`
  和 `cache_miss_tokens`。
- 模型目錄新增 `usage_capabilities`，呼叫前即可查詢模型可能回報的
  usage 維度與可計費維度。
- 新增 `GET /api/usage/requests/{request_id}`，可查詢單次請求的
  usage 維度、帳單明細、provider 原始快取欄位和路由資訊。
- 補充 Qwen/DashScope、DeepSeek、Anthropic、Gemini、OpenAI 和
  OpenRouter 的快取回報差異。
