# 更新履歴

## 2026-10-26 — 一部の API ルートの廃止予定

以下のルートは `Deprecation` と `Sunset` ヘッダーを返すようになりました。後継がある場合は `Link: <…>; rel="successor-version"` も返します。管理用ルートは 2026-12-01 以降、ユーザー向けルートと公開 API は 2027-02-01 以降に削除します。削除の前に本番のアクセス記録を確認します。

- `POST /api/user/self/stripe/pay`：`POST /api/user/stripe/pay` を使ってください。`POST /api/user/stripe/amount`：金額はコンソールで計算します。
- `/api/user/used-models`、`/api/user/models/classified`（`/api/user/models/catalog` へ）、`PUT /api/user/:id/has_topped_up`、`/api/data/self`（`/api/data/dashboard/self` へ）、`/api/log/token`（`/api/log/self` へ）、`/api/usage/token`（`/api/usage/summary` へ）、`/api/log/self/in_flight`（`/api/log/self/tasks` へ）、`/api/log/self/tasks/:id`。
- Playground のルート `/pg/chat/completions`。コンソールに Playground はもうありません。
- 501 を返す `/v1/fine-tunes*`、`/v1/images/variations`、`DELETE /v1/models/:model`、および残高 API `/v1/dashboard/billing/*`、`/dashboard/billing/*`。コンソールのウォレットが代わりになります。
- `/api/community/*` と `/api/models/rankings`。
- 管理用（2026-12-01 以降に削除）：`/api/channel/tag/*`、`/api/channel/batch*`（チャネルごとの操作へ）、`POST /api/notification/email/{send,announcement}`（お知らせ機能へ）、`/api/upload/*`（`config.yaml` の定期アップロードへ）、`/api/workers/*`。

## 2026-09-30 — Agent セッション、明細と長文脈料金

- タスク、モデル、個別請求明細を中心に Agent セッションを再構成しました。
- セッションの活動表示とサブエージェントのレーンを追加しました。ローカルツールの実行は観測対象外です。
- 長文脈料金を原価計算、請求明細、公開モデルページに接続しました。適用条件はモデルとレーンの設定によります。
- sitemap の更新日時を実際の内容変更日に修正しました。

日付はソースへのマージ日です。セルフホスト環境では導入バージョンを確認してください。[セッション費用の照合](/ja/agent-session-costs)も参照してください。

## 2026-05-28 — Usage メタデータとキャッシュフィールド

- OpenAI-compatible レスポンスに標準化されたキャッシュフィールド
  `cached_tokens`、`cache_write_tokens`、`cache_write_5m_tokens`、
  `cache_write_1h_tokens`、`cache_miss_tokens` を追加。
- モデルカタログに `usage_capabilities` を追加し、リクエスト前に
  報告可能な usage ディメンションと課金対象ディメンションを確認可能に。
- `GET /api/usage/requests/{request_id}` を追加し、リクエスト単位の
  usage、課金明細、provider raw cache fields、routing metadata を確認可能に。
- Qwen/DashScope、DeepSeek、Anthropic、Gemini、OpenAI、OpenRouter
  のキャッシュ報告差異をドキュメント化。

## 2026-05-12 — 静的ドキュメントを VPS に戻す

- `docs.lazu.ai` のアクティブなドキュメントアプリとして Vocs を復元。
- ドキュメントを独立した静的 nginx コンテナとして配信。
- Web サイトとドキュメントのプロダクトブランドと API 例を統一。

## 2026-05-09 — OpenAPI リファレンスの整理

- `packages/contracts/openapi/lazu-api-reference.v1.yaml` を信頼できる唯一のソースとして維持。
- build 時に OpenAPI JSON/YAML を docs の public assets に同期。
- リクエストとレスポンスのフィールド確認に使えるインタラクティブリファレンスを維持。
