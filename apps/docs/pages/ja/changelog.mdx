# 更新履歴

## 2026-11-24 — 複数 API レプリカでのメール認証

- メールによるログインと登録の認証コード、メールアドレス変更時の 2 つの確認コード、パスワード再設定リンクが、同じ認証ストアを使うようになりました。いずれも有効期限は 10 分で、1 回だけ使用できます。
- 単一プロセスの構成では、引き続きメモリ保存が既定です。API レプリカが複数ある場合は、すべてのレプリカで `REDIS_VERIFICATION_CODE_ENABLED=true` を設定し、同じ `REDIS_CONN_STRING` と `CRYPTO_SECRET` を使用してください。API を再起動してもコードは有効なままです。
- Redis が利用できない間は、検証できないコードを送らないよう、コードの発行と確認を停止します。
- Redis を有効にした後、または Redis を有効にしている構成を更新した後は、未使用のコードや再設定リンクを再発行してください。

## 2026-11-23 — 認証メール、モデル名、ログのダウンロード

- メールの件名に認証コードを含めないようにしました。メールログには、認証メールの固定件名と配信状況だけを保存し、本文は保存しません。スキーマ 40 への更新時に過去の記録も消去します。
- 削除されていないモデル名は、大文字と小文字、前後の空白を区別せずに一意になり、元の表記は保持されます。重複する名前で作成または名前変更すると `409`（`model_name_taken`）を返します。更新前に、大文字と小文字や前後の空白だけが異なるモデルの名前を変更するか削除してください。重複が残っていると新しい一意インデックスを作成できません。
- チャネルの保存時に、設定とルーティングをまとめて確定します。保存に失敗した場合はどちらも変更されません。
- ログのダウンロード（CSV と XLSX）と統計は、一覧と同じ期間、ユーザー、プロジェクトの絞り込みを使用します。
- 同梱の Compose ファイルは PostgreSQL を `127.0.0.1:10000` だけで公開します。他のホストからポート 10000 に接続していたツールは、SSH トンネルか Compose override を使用してください。

## 2026-11-23 — 旧 API と設定の廃止

- 以前告知した廃止日を今回のリリースに繰り上げます。コミュニティ、ランキング、Playground、旧残高照会、重複するユーザー API、管理者の入金済みマークを削除しました。残高はウォレットで確認できます。利用量、タスク、ダッシュボードには `/api/usage/summary`、`/api/log/self/tasks`、`/api/data/dashboard/self` を使用してください。
- 消費ログは常に記録され、金額は米ドルで表示されます。メディア取得は直接接続し、チャネルのフィールド設定は常に有効です。旧決済 outbox と時間別集計への書き込みを終了しました。更新前に既存の `usage_data` をバックアップし、未処理の outbox を v0.7.297 で精算してください。
- スキーマ 15 以前は v0.7.297 を経由して更新してください。新規インストールとスキーマ 16 以降は直接更新できます。
- 管理用ルート `/api/channel/tag/*`、`/api/channel/batch*`、`POST /api/notification/email/{send,announcement}`、`/api/upload/*`、`/api/workers/*` を、予定（2026-12-01 以降）より前に削除しました。チャネルごとの操作とお知らせ機能（公開時にメール送信も可能）を使用してください。`config.yaml` の定期アップロードとデータベースのバックアップは引き続き動作します。

## 2026-11-16 — アカウントのセキュリティ整理

- 新規登録はメール認証コードまたは有効な外部認証を使用します。ユーザー名とパスワードによる登録と `/register` を削除しました。既存ユーザーのパスワードログインは利用できます。
- メールの紐付けはログイン後に `POST /api/user/email/bind/start` と `POST /api/user/email/bind` を使用します。変更には新旧両方のメールの確認が必要です。従来の `GET /api/verification` と GET の紐付けルートは削除しました。
- 機能しない `POST /api/user/reset` を削除しました。パスワードの再設定は `/api/user/reset/v2` を引き続き使用します。
- `/api/log/token`、`/api/user/used-models`、`/api/user/models/classified`、`/api/user/self/stripe/pay`、`/api/user/stripe/amount` を削除しました。`/api/log/self`、モデルカタログ、`/api/user/stripe/pay` を使用してください。
- 未実装の `/v1/fine-tunes*`、`/v1/images/variations`、`DELETE /v1/models/:model` を削除しました。これらの削除は以前の廃止予定日に優先し、互換リダイレクトはありません。

## 2026-10-29 — 検索エンドポイントを削除

- `POST /v1/search` と `/api/search/backends*` を、予告していた 2026-11-01 より前に削除しました。下記のコンソールページ、ステータスページの検索行、API キーの検索フィールドも同時に削除しています。両ルートは 404 `endpoint_not_supported`（LZ-1010）を返します。
- エラーコード LZ-7302・LZ-7861・LZ-7862 は廃止しました。旧検索ドキュメントページはこの更新履歴へリダイレクトします。

## 2026-10-29 — 検索エンドポイントを非推奨化

- `POST /v1/search` と検索バックエンドの管理ルート（`/api/search/backends*`）を非推奨にしました。2026-11-01 以降の最初のリリースで削除します。これらのレスポンスには `Deprecation` と `Sunset` ヘッダーが付きます。api.lazu.ai ではこのエンドポイントを呼び出した顧客がいないため、通常の 90 日より短い期間にしています。
- 同時に削除するもの：コンソールの「検索バックエンド」ページ、ステータスページの検索行、API キーの `search_limits_enabled`・`search_providers`・`search_domain_allowlist` フィールド。
- 変更なし：モデル組み込みの Web 検索ツール（`/v1/responses` と Chat の `web_search`、`/v1/messages` の Claude Web 検索）は引き続き使え、課金も変わりません。`/v1/search` に依存するセルフホスト環境は、検索プロバイダーを直接呼び出してください。

## 2026-10-26 — セルフホスト向け設定 5 件を非推奨化

- `LogConsumeEnabled=false` を非推奨にしました。2027-01-24 以降、消費ログは常に記録されます。保存量の調整には `LOG_RETENTION_DAYS` を使ってください。
- Worker ダウンロードプロキシ（`WorkerUrl`、`WorkerValidKey`、`WorkerAllowHttpImageRequestEnabled`）を非推奨にしました。2027-01-24 以降、メディアのダウンロードと webhook は直接接続し、メディア取得ポリシーで宛先を確認します。
- `general_setting.quota_display_type=TOKENS` を非推奨にしました。2027-01-24 以降、ログ本文の金額はコンソールと同じく常に米ドルで表示されます。
- `SETTLEMENT_OUTBOX_ENABLED=true` を非推奨にしました。2027-01-24 以降、決済 outbox とその照合タスクは削除されます。失敗した決済は引き続き失敗照合タスクが回復します。
- `DataExportEnabled`（`DataExportInterval` を含む）を非推奨にしました。2027-02-01 以降、時間ごとの集計テーブル `usage_data` と `GET /api/data/` を削除します。ダッシュボードと利用状況ページはこれらを読みません。残す場合は先にテーブルをエクスポートしてください。
- いずれかを設定しているデプロイでは、起動時に `deprecated setting:` で始まるログが出力されます。詳しくはデプロイガイドの「Deprecated settings」をご覧ください。
## 2026-10-26 — 一部の API ルートの廃止予定

以下のルートは `Deprecation` と `Sunset` ヘッダーを返すようになりました。後継がある場合は `Link: <…>; rel="successor-version"` も返します。管理用ルートは 2026-12-01 以降、ユーザー向けルートと公開 API は 2027-02-01 以降に削除します。削除の前に本番のアクセス記録を確認します。

- `POST /api/user/self/stripe/pay`：`POST /api/user/stripe/pay` を使ってください。`POST /api/user/stripe/amount`：金額はコンソールで計算します。
- `/api/user/used-models`、`/api/user/models/classified`（`/api/user/models/catalog` へ）、`PUT /api/user/:id/has_topped_up`、`/api/data/self`（`/api/data/dashboard/self` へ）、`/api/log/token`（`/api/log/self` へ）、`/api/usage/token`（`/api/usage/summary` へ）、`/api/log/self/in_flight`（`/api/log/self/tasks` へ）、`/api/log/self/tasks/:id`。
- Playground のルート `/pg/chat/completions`。コンソールに Playground はもうありません。
- 501 を返す `/v1/fine-tunes*`、`/v1/images/variations`、`DELETE /v1/models/:model`、および残高 API `/v1/dashboard/billing/*`、`/dashboard/billing/*`。コンソールのウォレットが代わりになります。
- `/api/community/*` と `/api/models/rankings`。
- 管理用（2026-12-01 以降に削除）：`/api/channel/tag/*`、`/api/channel/batch*`（チャネルごとの操作へ）、`POST /api/notification/email/{send,announcement}`（お知らせ機能へ）、`/api/upload/*`（`config.yaml` の定期アップロードへ）、`/api/workers/*`、`GET /api/data/`（読み出し元の `usage_data` テーブルも非推奨）。

## 2026-09-30 — Agent セッション、明細と長文脈料金

- タスク、モデル、個別請求明細を中心に Agent セッションを再構成しました。
- セッションの活動表示とサブエージェントのレーンを追加しました。ローカルツールの実行は観測対象外です。
- 長文脈料金を原価計算、請求明細、公開モデルページに接続しました。適用条件はモデルとレーンの設定によります。
- sitemap の更新日時を実際の内容変更日に修正しました。

日付はソースへのマージ日です。セルフホスト環境では導入バージョンを確認してください。[セッション費用の照合](/ja/agent-session-costs)も参照してください。

## 2026-05-28 — Usage メタデータとキャッシュフィールド

- OpenAI-compatible レスポンスに標準化されたキャッシュフィールド
  `cached_tokens`、`cache_write_tokens`、`cache_write_5m_tokens`、
  `cache_write_1h_tokens`、`cache_miss_tokens` を追加。
- モデルカタログに `usage_capabilities` を追加し、リクエスト前に
  報告可能な usage ディメンションと課金対象ディメンションを確認可能に。
- `GET /api/usage/requests/{request_id}` を追加し、リクエスト単位の
  usage、課金明細、provider raw cache fields、routing metadata を確認可能に。
- Qwen/DashScope、DeepSeek、Anthropic、Gemini、OpenAI、OpenRouter
  のキャッシュ報告差異をドキュメント化。

## 2026-05-12 — 静的ドキュメントを VPS に戻す

- `docs.lazu.ai` のアクティブなドキュメントアプリとして Vocs を復元。
- ドキュメントを独立した静的 nginx コンテナとして配信。
- Web サイトとドキュメントのプロダクトブランドと API 例を統一。

## 2026-05-09 — OpenAPI リファレンスの整理

- `packages/contracts/openapi/lazu-api-reference.v1.yaml` を信頼できる唯一のソースとして維持。
- build 時に OpenAPI JSON/YAML を docs の public assets に同期。
- リクエストとレスポンスのフィールド確認に使えるインタラクティブリファレンスを維持。
