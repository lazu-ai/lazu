# Lazu と Helicone

[Helicone](https://github.com/Helicone/helicone) は LLM アプリケーション向けの観測プラットフォームで、ゲートウェイとしても働きます。ベース URL を変え、Helicone のキーを加えれば、すべてのリクエストがコスト、レイテンシ、トークンとともに記録されます。Lazu はまずゲートウェイです。アカウント、予算、リクエストごとの利用記録を持ち、コンソールとドキュメントは同じ製品に含まれます。両者は「すべてのリクエストの記録」で重なり、その記録が何のためにあるかで分かれます。事実は 2026 年 11 月 2 日に確認しました。

## それぞれ誰向けか

**Helicone** は、自分のアプリケーションが何をしているかを見たい AI エンジニア向けです。ダッシュボード、セッションとトレース、リクエスト別コスト、有料プランではアラートとレポート。デフォルトはホスト型サービスで、セルフホスト用イメージには Web アプリ、API、オブジェクトストア、データベースが同梱されますが、ゲートウェイは別にデプロイし、Helm チャートは会社への問い合わせが必要です。

**Lazu** は、人とエージェントにキーを配り、誰がいくら使ったかに答える必要があるチーム、研究室、企業向けです。各キーには呼び出し前に予約される予算があり、各リクエストには持ち主が読める記録が残り、運営者は全体を 1 台のサーバーで動かします。

## 並べて見る

| 形態 | プロキシ付きの観測プラットフォーム（TypeScript）。別の Rust ゲートウェイリポジトリは 2025 年 11 月以降コミットなし | Go ゲートウェイと worker、React コンソール、Vocs ドキュメント。1 つの Docker Compose スタック |
| デプロイ | デフォルトはホスト型。セルフホスト用の `helicone-all-in-one` Docker イメージ、ゲートウェイは同梱なし。Helm は会社への問い合わせ経由 | PostgreSQL と Redis を含む 1 つの Docker Compose スタック |
| 設定 | `Helicone-*` リクエストヘッダー | 上流、価格、ユーザー、お知らせはコンソール |
| アカウント | 組織とプラン別のシート | ユーザー、チームとプロジェクト、メンバー予算、API キー |
| 予算 | キー別予算の記載なし。時間窓ごとのリクエスト数またはコストによるレート制限、到達時は `429` | 前払い残高。キー別上限、プロジェクトと支出予算。呼び出し前に予約、プロバイダーのカウンターで精算、失敗時に解放 |
| 利用記録 | 全リクエストのコスト、レイテンシ、トークン。セッションとトレース。保持期間はプラン次第 | リクエストごとに 1 件、利用量・計測元・課金明細付きで、送ったキーが読める。エージェントセッション。照合スクリプト |
| ルーティング | ホスト型ゲートウェイでのルーティングと自動フォールバック | モデルごとに優先度と重みでチャネル選択、ヘルスウィンドウ、同一モデルでの再試行。公開の経路ヘルスページ |
| プロトコル | OpenAI 風の構文で OpenAI、Anthropic、Google、Bedrock へ | OpenAI、Anthropic Messages、Gemini をネイティブに。無損失のときだけ変換 |
| 有料版 | Hobby（無料）、Pro、Team、Enterprise：アラートとレポート、HQL、SOC 2 と HIPAA、SAML SSO、オンプレミス | なし |
| ライセンス | Apache-2.0（プラットフォーム） | AGPL-3.0-or-later |

## お金

Helicone は支出を計測しますが、残高は持ちません。カスタムのレート制限ポリシーで時間窓ごとのリクエスト数やセント額に上限を設けて `429` を返せますが、キーを恒久的に止めるキー別予算はなく、制限はホスト型のインフラ上で動きます。Lazu はお金を預かります。上流を呼ぶ前に前払い残高から見積額を予約し、プロバイダーが報告した利用量で精算し、各次元をプロバイダー計測、ローカル推定、取得不能のいずれかとして記録し、アカウントが賄えないリクエストはプロバイダーに届きません（[課金契約](https://github.com/lazu-ai/lazu/blob/main/docs/billing-contract.md)）。

## リクエストが残すもの

ここが両者の最も近いところです。Helicone の記録はデバッグと分析のために作られています。セッション、トレース、プロパティ、有料プランではクエリ言語。Lazu の記録は精算のために作られています。正規化された利用量、そのうちプロバイダーが計測した数値と推定された数値、課金明細、公開タイミングを、リクエストを送ったキーが取得できます（[リクエスト詳細](/ja/endpoints/usage-requests)）。エージェントのリクエストはセッションにまとめられ、[スクリプト](https://github.com/lazu-ai/lazu/blob/main/ops/scripts/summarize-agent-session.py)がエクスポートしたセッションをオフラインで照合します。両方が欲しいなら、Lazu は観測ツールの後ろに置けます。両者は代替品ではありません。

## Helicone にあって Lazu にないもの

- アプリケーションのデバッグのために作られたダッシュボード、セッション、トレースと、それらに対するクエリ言語。
- アラートと定期レポート。
- OpenTelemetry エクスポートと、ログ用の MCP サーバー。
- 何も動かさなくてよいホスト型サービス。

## どちらを選ぶか

- すでに動かしているアプリケーションを観察したく、キーと請求は他の誰かが持っているなら **Helicone**。
- キーを発行し残高を預かるのが自分で、各リクエストの記録が精算に耐えるものでなければならないなら **Lazu**。
