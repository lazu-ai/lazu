## 例：セマンティック検索

ドキュメントを一度ベクトル化し、クエリごとにベクトル化して、コサイン類似度で並べます。`BAAI/bge-m3` は 100 以上の言語を同じベクトル空間に写すので、英語のクエリで中国語や日本語のドキュメントを翻訳なしで見つけられます。

```python
import numpy as np
from openai import OpenAI

client = OpenAI(base_url="https://api.lazu.ai/v1", api_key="YOUR_LAZU_KEY")

docs = [
    "Reset your password from Settings → Security.",
    "账单每月 1 日生成，可在控制台下载发票。",
    "API キーはプロジェクトごとに発行できます。",
]

def embed(texts):
    resp = client.embeddings.create(model="BAAI/bge-m3", input=texts)
    vectors = np.array([item.embedding for item in resp.data])
    return vectors / np.linalg.norm(vectors, axis=1, keepdims=True)

doc_vectors = embed(docs)
query_vector = embed(["Where can I download my invoice?"])[0]

scores = doc_vectors @ query_vector
for index in scores.argsort()[::-1]:
    print(f"{scores[index]:.3f}  {docs[index]}")
```

## 制限

- **1 入力あたりのトークン上限。** カタログの `input_limit` は 1 入力に含められる最大トークン数です（`BAAI/bge-m3` は 8192）。超えた入力は `400 context_length_exceeded`（LZ-1005）で拒否され、課金されません。長い文書は上限未満のチャンクに分けてください。1 チャンク数百〜1000 トークン程度のほうが検索精度も上がりやすくなります。
- **バッチ。** 配列を渡すと複数テキストを 1 リクエストでベクトル化できます。大量処理では 1 バッチ数十〜数百件にし、失敗したバッチだけ再試行してください。
- **空入力。** 多くのモデルは空文字列を拒否します。送信前に空のチャンクを除いてください。

## 課金

Embeddings は入力トークンのみ課金され、単価は[料金とライン](/ja/models/pricing)の入力価格です。プロバイダーが読み取ったトークン数を返す場合はその数で課金し、返さない場合は Lazu が汎用トークナイザーでローカルに数えます。モデル固有のトークナイザーとは言語によって数パーセント前後することがあります。失敗したリクエストは課金されません。各リクエストの課金トークン数と金額は `usage` とリクエスト詳細で確認できます。

## 主なモデル

| モデル                   | 次元 | 1 入力の最大トークン | `dimensions` 指定   | 備考                         |
| ------------------------ | ---- | -------------------- | ------------------- | ---------------------------- |
| `BAAI/bge-m3`            | 1024 | 8192                 | 不可                | オープンウェイト、100+ 言語  |
| `text-embedding-3-small` | 1536 | 8191                 | 可                  | OpenAI、低コスト             |
| `text-embedding-3-large` | 3072 | 8191                 | 可                  | OpenAI、最高品質             |
| `gemini-embedding-001`   | 3072 | 2048                 | 可（768、1536）     | Google                       |

キーで呼び出せるモデルはデプロイによって異なります。モデルカタログが正です。
