## 托管版配置

`/v1/search` 的实现支持 Tavily、Serper、Exa、Jina 和 Brave，但请查看当前展示的搜索价格，并在请求详情核对 `web_search` 计费明细；不要根据旧示例或部署配置推断搜索免费。

| Backend     | 托管版状态 | 能力                                | 说明                                                                  |
| ----------- | ---------- | ----------------------------------- | --------------------------------------------------------------------- |
| Tavily      | 已启用     | `web_search`、`web_fetch`、`answer` | 支持 `include_answer` 和 `search_depth`；`advanced` 按 2 units 计算。 |
| Serper      | 已启用     | `web_search`                        | 会映射 `country` / `region`、`language` 和 `time_range`。             |
| Jina        | 已启用     | `web_search`、`web_fetch`           | 使用 `https://s.jina.ai`，更适合 retrieval 风格的 snippet。           |
| Exa / Brave | 代码支持   | 管理员配置后支持 `web_search`       | 适用于自部署或管理员后续配置的托管环境。                              |

当前托管版 backend 使用默认策略：每次请求最多返回 10 条结果，上游 timeout 为 8s。
如果请求里的 `max_results` 更大，Lazu 会按选中的 backend policy 截断。

## 请求 Body

<FieldList>
  <Field name="query" type="string" required>
    搜索 query。当前 MVP 每次请求支持一个 query。
  </Field>
  <Field name="type" type="string" nullable values={["web", "news"]}>
    搜索类型，默认 <code>web</code>。
  </Field>
  <Field name="backend" type="string" nullable>
    <code>auto</code>、provider 名称如 <code>tavily</code> /<code>serper</code>
    ，或已配置的 backend ID/name。默认 <code>auto</code>。
  </Field>
  <Field name="region" type="string" nullable>
    地区 hint。Serper 会映射到 <code>gl</code>。
  </Field>
  <Field name="language" type="string" nullable>
    语言 hint，例如 <code>en</code> 或 <code>zh-CN</code>。
  </Field>
  <Field
    name="time_range"
    type="string"
    nullable
    values={["day", "week", "month", "year"]}
  >
    时间范围 hint。provider 不支持时可能忽略。
  </Field>
  <Field name="max_results" type="integer" nullable>
    返回结果数。默认 <code>10</code>，并受 backend policy 上限约束。
  </Field>
  <Field
    name="search_depth"
    type="string"
    nullable
    values={["basic", "advanced"]}
  >
    provider 深度 hint。Tavily <code>advanced</code> 会消耗 2 个计费 unit。
  </Field>
  <Field name="include_answer" type="boolean" nullable>
    selected backend 返回 answer 时一并返回。Lazu 不在这个 endpoint
    内生成最终答案。
  </Field>
  <Field name="include_raw_content" type="boolean" nullable>
    provider 返回原文或清洗正文时是否透出，默认 <code>false</code>。
  </Field>
  <Field name="include_domains" type="string[]" nullable>
    限制搜索域名。token 级 domain allowlist 仍会生效。
  </Field>
  <Field name="exclude_domains" type="string[]" nullable>
    排除域名，取决于 selected backend 是否支持。
  </Field>
  <Field name="include_provider_payload" type="boolean" nullable>
    返回 provider 原始 payload，主要用于排障。默认 <code>false</code>。
  </Field>
  <Field name="provider_options" type="object" nullable>
    高级 provider passthrough。只会使用当前 provider 对应对象，例如{" "}
    <code>{'{"serper":{"tbs":"qdr:d"}}'}</code>。
  </Field>
</FieldList>

## 计费

Search backend 的价格来自配置里的 <code>search_price</code>。这个值表示每个
provider billing unit 的 USD 价格，不一定等同于每个 HTTP request 的价格。
当前托管版 Tavily、Serper 和 Jina 没有显式配置 <code>search_price</code>，
所以 Lazu 会记录 <code>web_search</code> usage，但 search line item 费用为
$0；后续管理员配置价格或 provider-cost passthrough 后才会按配置收费。

| Backend | Unit 映射                                                        |
| ------- | ---------------------------------------------------------------- |
| Tavily  | <code>basic</code> = 1 credit；<code>advanced</code> = 2 credits |
| Serper  | 1 个成功 query = 1 unit                                          |
| Jina    | 1 个成功 query = 1 unit                                          |

上游失败、timeout、参数错误会按 Lazu 常规计费规则 refund。
