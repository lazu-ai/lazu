## 示例：语义检索

文档先向量化一次，每个查询再向量化，按余弦相似度排序。`BAAI/bge-m3` 把 100 多种语言映射到同一个向量空间，英文查询不用翻译就能找到中文或日文文档。

```python
import numpy as np
from openai import OpenAI

client = OpenAI(base_url="https://api.lazu.ai/v1", api_key="YOUR_LAZU_KEY")

docs = [
    "Reset your password from Settings → Security.",
    "账单每月 1 日生成，可在控制台下载发票。",
    "API キーはプロジェクトごとに発行できます。",
]

def embed(texts):
    resp = client.embeddings.create(model="BAAI/bge-m3", input=texts)
    vectors = np.array([item.embedding for item in resp.data])
    return vectors / np.linalg.norm(vectors, axis=1, keepdims=True)

doc_vectors = embed(docs)
query_vector = embed(["Where can I download my invoice?"])[0]

scores = doc_vectors @ query_vector
for index in scores.argsort()[::-1]:
    print(f"{scores[index]:.3f}  {docs[index]}")
```

## 限制

- **单条输入 token 上限。** 目录里的 `input_limit` 是一条输入最多能有多少 token（`BAAI/bge-m3` 为 8192）。超长输入会被拒绝，返回 `400 context_length_exceeded`（LZ-1005），不扣费。长文档请先切块到上限以下；每块几百到一千 token 通常检索效果也更好。
- **批量。** 传数组即可一次向量化多条文本。大任务建议每批几十到几百条，失败时重试那一批，而不是发一个超大请求。
- **空输入。** 多数模型会拒绝空字符串，发送前请去掉空块。

## 计费

Embeddings 只按输入 token 计费，单价见[定价与渠道](/zh/models/pricing)里该模型的输入价。服务商返回了读取的 token 数时按它计费；没有返回时，Lazu 用通用分词器在本地计数，与模型自带分词器相比可能相差几个百分点，偏多偏少取决于语言。失败的请求不扣费。每次请求的计费 token 和金额都在 `usage` 和请求详情里。

## 常见模型

| 模型                     | 维度 | 单条最大输入 token | 自定义 `dimensions` | 说明                     |
| ------------------------ | ---- | ------------------ | ------------------- | ------------------------ |
| `BAAI/bge-m3`            | 1024 | 8192               | 不支持              | 开放权重，100+ 种语言    |
| `text-embedding-3-small` | 1536 | 8191               | 支持                | OpenAI，低成本           |
| `text-embedding-3-large` | 3072 | 8191               | 支持                | OpenAI，效果最好         |
| `gemini-embedding-001`   | 3072 | 2048               | 支持（768、1536）   | Google                   |

你的 Key 能调用哪些模型取决于部署，以模型目录为准。
