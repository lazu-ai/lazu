# Lazu よくある質問：Claude・GPT API の料金、支払い方法、ライン

## Lazu をセルフホストできますか?

Lazu は現在 lazu.ai のホスティングサービスとして提供しています。専用環境やオンプレミス導入が必要な場合はお問い合わせください。

## 対応モデル数は？

呼び出せるモデルはすべて lazu.ai/models に、リアルタイムの価格と直近 7 日間の稼働率つきで掲載しています。OpenAI、Anthropic、Google、DeepSeek、Moonshot（Kimi）、Zhipu（GLM）、Alibaba（Qwen）、MiniMax のモデルです。キーで GET /api/models/catalog を呼ぶと、そのキーで使える同じ一覧が返ります。

## どのモデルメーカーに対応していますか？

OpenAI、Anthropic、Google、DeepSeek、Moonshot（Kimi）、Zhipu（GLM）、Alibaba（Qwen）、MiniMax です。新しいモデルは提供開始後、モデル一覧と更新履歴に追加されます。

## OpenAI からどう移行しますか？

変更は2行です。base_url を https://api.openai.com/v1 から https://api.lazu.ai/v1 に変更し、api_key を Lazu key に差し替えます。アプリケーションコードは公式 OpenAI Python、JavaScript、Go SDK をそのまま利用できます。

## 中国から Claude と GPT を直接使えますか？

はい。Lazu のエンドポイント https://api.lazu.ai を使えば、中国国内の IP から VPN やプロキシなしで直接接続できます。各モデルのページで直近 7 日間の稼働率を確認できます。

## 料金はどう計算されますか？

入力・出力・キャッシュの token を個別に計測し、利用するレーンの公開価格で課金します。月額料金や最低利用額はありません。

## 安定ラインとAgent ラインの違いは？

安定ラインは各社の公式 API を使い、表示価格で課金され、稼働率が最も高く、あらゆる用途に向いています。Agent ラインはサードパーティのサブスクリプションプールが公式クライアント経由で提供するもので、公式 API ではありません。料金は大幅に安い一方、稼働率は変動し、失敗しても安定ラインには切り替わらず、プールが独自のプリセットコンテキストを付けます。そのため、対応する Agent ツールでの利用に限って推奨します（Claude モデルは Claude Code、GPT モデルは Codex、Gemini モデルは Antigravity）。自作のプログラムや出力を厳密に制御したい場面では安定ラインを使ってください。どちらも同じ Key で使え、Key ごと・モデルごとにラインを選べます。

## どの支払い方法に対応していますか？

Stripe によるオンラインチャージに対応しています。Visa・Mastercard などのカードと Alipay が使えます。残高は米ドル建てです。

## データをモデル学習に使いますか？どのように保存されますか？

使いません。Lazu はお客様のデータをモデル学習に使いません。リクエストとレスポンスの内容はリクエストログに記録し、個別のリクエストをお客様と一緒に確認できるよう 180 日間保持した後に削除します。利用記録はメタデータ（時刻、モデル、token 数、料金、ステータス、request_id）のみを 90 日間保持します。

## ストリーミング応答に対応していますか？

はい。Chat completion 系 endpoint は stream: true で SSE ストリーミングを利用でき、OpenAI 互換の挙動です。

## Anthropic ネイティブ API に対応していますか？

はい。OpenAI 互換の /v1/chat/completions に加え、Lazu は x-api-key と anthropic-version header を使う /v1/messages も提供します。Extended Thinking、Prompt Caching、Tool Use はこの経路で利用できます。

## レート制限は？

レート制限はモデルとアカウントによって変わります。コンソールでリアルタイムの使用量と制限を確認できます。より高い RPM / TPM が必要な場合は support@lazu.ai までご連絡ください。

## 使用量とコストはどう監視できますか？

コンソールには日次、週次、月次の利用ダッシュボードがあり、モデル、endpoint、token 種別ごとに分解できます。すべてのリクエストには x-request-id が付与され、ログページで検索できます。

## エラーはどう調査しますか？

すべてのレスポンスには x-request-id ヘッダーが含まれます。コンソールの利用ログでこの ID を検索すると、リクエスト時刻、利用したレーン、ステータス、token の課金明細、エラーの詳細を確認できます。

## 新規向けの特典はありますか？

初回チャージは 10% 上乗せ（最大 $10）で、チャージと同時に反映されます。登録だけでは残高は付与されず、チャージ後の返金はできません。

## 紹介特典はありますか？

あります。ウォレットで紹介リンク（lazu.ai/?ref=あなたの名前）をコピーするか、lazu.ai のどのリンクにも ?ref=あなたの名前 を付けてください。友だちがそのリンクから登録してから 30 日間、支払ったチャージの 10%（1 人あたり最大 $30）が各 7 日後にあなたに付与されます。対象は 1 人あたり最大 100 人で、同じチームの人は対象外です。特典は Lazu の残高で、出金はできません。
