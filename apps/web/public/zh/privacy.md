# 隐私政策

最近更新日期：2026 年 10 月 2 日

Lazu 是由 DUBRIO LLC（以下简称“DUBRIO”或“我们”）提供并运营的 AI 模型 API 聚合、路由、用量与计费服务。本隐私政策说明你访问 `https://lazu.ai`、创建 Lazu 账户、使用 Lazu API 或控制台功能，或联系我们时，我们会处理哪些信息以及如何处理。

创建账户或使用本服务，即表示你知悉本政策所述的处理方式。适用法律要求另行取得同意时，我们会单独征求你的同意。

## 一、我们处理的信息

### 1. 账户与身份验证信息

- 使用密码注册时，我们会处理你的用户名、显示名称、邮箱地址以及单向哈希后的密码；我们不保存明文密码。
- 选择 Google 登录时，我们只申请 `openid`、`email` 和 `profile` 权限，并接收你的 Google 稳定账户标识、姓名和已验证邮箱。我们不会申请访问 Gmail、Google Drive、Google 通讯录、日历或其他 Google 产品内容。
- 选择 GitHub 登录时，我们会接收你的 GitHub 稳定账户标识、用户名或显示名称以及已验证邮箱。
- 为创建、关联、保护和恢复 Lazu 账户，我们会保存外部身份提供方名称、该提供方的账户标识和已验证邮箱。登录流程完成后，我们不会保留 Google 或 GitHub 访问令牌。

### 2. API 使用与运营信息

为提供服务与计费，我们会处理账户及 API Key 标识、请求标识、所选模型与供应商、时间、token 或其他计量单位、价格和额度流水、延迟、状态与错误信息、IP 地址、大致国家或地区，以及客户端框架或版本等记录。

你的 API 输入、上传内容和模型输出会在提供服务所需的过程中传输和处理，并可能被发送给你选择或由路由配置选定的模型供应商。我们还会在请求日志中记录 API 请求和响应的内容，保留期限见「五、保留与删除」。Lazu 不会使用你的输入或输出训练模型，也不会将其出售用于广告。模型供应商会按照各自的条款和数据政策处理内容，不同供应商和通道的政策可能不同。

如果你使用会主动保存内容的功能（例如 Files API），我们会保存文件及相关元数据，直至你删除或适用的保留规则将其清除。你主动提交的支持材料，或安全调查所必需的信息，也可能在解决问题期间被临时处理。

### 3. 支付与交易信息

银行卡支付由 Stripe Checkout 处理。我们会处理 Lazu 订单号、Stripe Customer ID、金额、币种、支付状态、支付方式类型、收据邮箱、购买额度和已消费额度等交易记录。完整卡号和安全码由 Stripe 直接收集，不会经过或保存在 Lazu 服务器上。

如果 Lazu 日后在结账页展示稳定币或其他链上支付选项且你选择使用，我们可能处理完成购买与对账所需的钱包地址、区块链网络、资产、金额、交易哈希、确认数与支付状态、服务商或订单标识，以及反欺诈或合规筛查结果。区块链记录公开且通常不可更改，支付处理商、区块链网络、浏览器或分析服务可能独立处理这些信息。Lazu 绝不会要求或保存你的私钥或助记词。钱包付款本身不能证明付款人的法定身份。本段仅在结账页实际提供链上选项时适用；Lazu 目前并不表示该选项已经上线。

### 4. 设备、Cookie 与沟通信息

我们会处理浏览器与设备特征、语言、时区、Cookie 或本地存储标识以及安全日志等技术信息。你联系我们时，我们会处理为回复所需的消息内容、联系方式及相关支持记录。

你第一次访问时，我们会把你从哪里来（utm_source 等推广参数、来源网站和落地页面）保存在一个第一方 Cookie 中，最长 30 天。如果你随后注册，我们会保留这条来源、你的注册方式和所在国家（不含 IP 地址），用于了解哪些渠道把人带到了 Lazu。

我们还使用一个随机的第一方浏览器标识（保存最长 30 天），将带推广参数的访问与后续注册关联。你打开带 UTM 参数或推荐码的链接时，即使尚未注册，我们也会记录推广字段、推荐码、落地路径（不含查询参数和片段）、来源网站域名及服务器时间。访问记录保留 90 天，不包含 IP 地址或完整来源网址。后续推广访问不会覆盖首次注册来源；推荐奖励使用最近一次有效推荐码。删除账号时会删除关联的归因记录。

注册后，我们可能会请你选一下是从哪里知道 Lazu 的（例如某个 AI 助手、搜索引擎或社区）。这一步可以跳过；你的选择与上面的注册来源一起保存，删除账号时一并删除。

### 5. Lazu Studio 创作信息

你在 Lazu Studio 生成图片或视频时，我们会保存你的提示词、所选模型和参数、你添加的参考图、生成的作品文件，以及每次实际扣费的金额。作品默认只有你自己看得到；你申请公开并通过审核后，作品及其提示词、模型和参数会显示在公开页面上，可能被搜索引擎收录，并附上由我们的文字模型生成的标题和分类。你可以随时取消公开。

为防止滥用，你下载原图和领取每天的免费生成时，我们会记录 IP 地址。你在 Studio 里搜索时，我们会记录搜索词，用于改进搜索和相关推荐。

## 二、我们如何使用信息

我们将信息用于：

1. 创建、验证、关联、保护和管理账户；
2. 路由模型请求并返回响应；
3. 统计用量、维护余额、处理付款并发送收据；
4. 提供文件、控制台、支持和账户恢复功能；
5. 发现欺诈、滥用、攻击以及违反服务条款的行为；
6. 排查故障并提升可靠性与性能；
7. 发送服务、安全、账单和政策更新；
8. 遵守适用法律并执行相关协议。

我们不会使用 Google 用户数据、支付信息或 API 内容评估信用，也不会据此投放个性化广告。

## 三、我们如何共享信息

我们不出售个人信息。仅在合理必要范围内向以下对象披露信息：

1. **模型供应商**：将请求发送给你使用的模型或通道，并接收输出。
2. **身份提供方**：完成 Google、GitHub 或管理员配置的企业身份提供方登录及账户关联。
3. **支付服务商**：由 Stripe 完成结账、付款确认、反欺诈和收据服务；如日后启用链上支付，则由结账页披露的加密支付、区块链和合规服务商完成付款与对账。
4. **基础设施与服务供应商**：在适当的保密与安全义务下提供托管、数据库、对象存储、邮件、监控和客户支持。
5. **主管机关与权益保护**：响应有效法律程序，或保护用户、DUBRIO 及公众免受欺诈、滥用和安全威胁。
6. **业务变更**：在合并、融资、重组或出售时，根据适用的通知与保护要求进行必要转移。

## 四、Google API 数据

Lazu 对从 Google API 获得的信息的使用和传输遵守 [Google API 服务用户数据政策](https://developers.google.com/terms/api-services-user-data-policy)，包括其中的 Limited Use（有限使用）要求。

Google 账户信息仅用于面向用户的身份验证、账户关联、账户安全和用户请求的支持。我们不会出售 Google 用户数据，不会将其用于广告，也不会提供给数据经纪商。你可在 Google 账户的第三方访问权限中撤销 Lazu 授权。撤销后将无法继续使用 Google 登录，但不会自动删除 Lazu 账户或我们依法必须保留的记录；你可以按照下文申请删除。

## 五、保留与删除

- 请求日志（包含 API 请求和响应的内容）保留 180 天，便于我们与你一起回查具体请求、排查故障和防止滥用，到期后删除。
- 用量记录（请求标识、模型、token 用量、费用、状态和耗时，不含请求和响应内容）保留 90 天。
- 账户、外部身份、余额、账本、支付、安全和审计记录会在账户存续期间保留；账户关闭后，为完成关闭、反欺诈、争议处理、会计、税务和法律义务所合理必要的部分仍可能继续保留。
- 如启用链上支付，相关交易哈希和对账记录可能因同样目的被保留；写入公共区块链的信息无法由 Lazu 删除或更改。
- 已存储文件会保留至用户删除或适用的产品保留规则将其清除。
- Lazu Studio 未公开作品的文件保存 180 天，到期前 7 天提醒你下载，到期后删除；取消公开会重新开始计算 180 天。公开作品在保持公开期间一直保存。
- Lazu Studio 的下载记录和每日免费生成记录（含 IP 地址）保存 90 天；Studio 搜索词保存 90 天。
- 信息不再必要时，我们会删除或去标识化处理，但法律要求或允许继续保留的除外。

如需申请删除账户和个人数据，请联系 `support@lazu.ai`。我们可能需要验证你对账户的控制权。删除 Lazu 账户不会影响模型、身份或支付供应商已根据其自身政策独立处理的数据，也不会删除 Lazu 无法控制的公共区块链记录。

## 六、你的选择与权利

根据适用法律，你可以请求访问、更正、删除、限制处理或导出信息，撤回同意，或对特定处理提出异议。你可以在控制台更新可修改的资料、在第三方平台撤销登录授权、停用 API Key、删除已存储文件，或申请删除账户。

我们采取合理的管理与技术措施，包括加密传输、访问控制、密码哈希、权限受限的凭据及安全监控。任何互联网服务均无法保证绝对安全。你应妥善保管账户凭据和 API Key，并在发现疑似滥用时及时通知我们。

## 九、未成年人

Lazu 主要面向成年人和企业用户，并非面向 13 岁以下儿童。如你认为儿童在未获得适当授权的情况下向我们提供了个人信息，请联系我们，我们会按照适用要求进行审查和删除。
